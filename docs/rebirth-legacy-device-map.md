# 旧设备模块与能力映射

日期：2026-10-17。已知事实固定于Legacy提交`5d60491d7158f87fc27b564f510d321074aedac9`，本轮仅核验源码与测试存在，未运行设备或测试。覆盖OBS、ATEM、Mixer、VB控制及各自Seamer适配，共8个bundle；与[排期5模块](rebirth-legacy-schedule-map.md)、[其余5模块](rebirth-legacy-system-map.md)合计18个bundle的来源范围盘点。**这不等于每个能力的新版参数／证据契约已冻结或全部功能已验收。**

新版目标是Controller保留独立手动控制，SDK公开完整能力与目录，GUI保留专用操作流，Seamer按受控API调用。不能只迁移旧Seamer manifest而遗漏独立面板功能。[C09](rebirth-c09-extension-design.md)约束全部入口；下面“新要求”均为待审阅映射，不是已修复代码。
